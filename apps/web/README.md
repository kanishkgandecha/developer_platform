# @developer-platform/web

Next.js (App Router) frontend for the Developer Platform. Part of a pnpm/Turborepo monorepo —
see the [repo root README](../../README.md) and [docs/development.md](../../docs/development.md)
for setup, and [docs/architecture.md](../../docs/architecture.md) for how this app talks to
`apps/api`.

```bash
pnpm --filter @developer-platform/web dev
```
